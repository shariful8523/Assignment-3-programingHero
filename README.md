# Rinterio – Modern Architectural Landing Page

**Rinterio** is a modern, responsive landing page template designed to showcase architectural designs, particularly barn houses. It highlights services, portfolio, and contact information with an elegant and user-friendly interface.

---

## 🚀 Features

- Fully **responsive design** for mobile, tablet, and desktop.  
- **Interactive Navbar** with dropdown menu for mobile devices.  
- **Hero Banner Section** with captivating visuals and text overlay.  
- **About Us Section** with collapsible cards for services.  
- **Our Works Process Section** with informative workflow cards.  
- **Portfolio Section** showcasing latest projects with images and view buttons.  
- **Next Project Showcase** featuring upcoming projects with hover effects.  
- **Contact Form Section** for users to connect directly.  
- **Footer Section** with quick navigation links and a “Book Consult” button.  
- **Typography & Icons**: Google Fonts (Manrope) and FontAwesome icons for a modern look.  
- **Tailwind CSS & DaisyUI** integration for easy styling and layout management.

---

## 🛠 Technologies Used

- **HTML5** – Semantic markup and structure.  
- **Tailwind CSS** – Utility-first CSS framework for rapid design.  
- **DaisyUI** – Component library built on Tailwind CSS.  
- **FontAwesome** – Icon library for interactive elements.  
- **Google Fonts (Manrope)** – Modern, readable typography.  
- **JavaScript** – Minimal JS for Tailwind configuration and interactivity.
